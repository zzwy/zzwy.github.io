# Weiyu Zhou Personal Homepage

A clean GitHub Pages-ready personal academic homepage.

## How to use

1. Create a GitHub repository named `your-github-id.github.io`.
2. Upload `index.html` and the `assets/` folder to the repository root.
3. Replace placeholders:
   - `your_email@example.com`
   - `your-github-id`
   - `files/cv.pdf`
   - portrait placeholder in `assets/img/` if needed
4. Open `https://your-github-id.github.io`.
